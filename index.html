Questions fréquentes

Où sont stockées mes données ?

Uniquement sur votre iPhone. Il n'y a ni compte ni serveur : l'éditeur n'a accès à aucune de vos informations.

Comment parcourir mon mois sur le cadran ?

Restez appuyé sur le cadran de l'écran Aperçu, puis faites glisser votre doigt autour : chaque jour s'affiche au centre avec ses prélèvements.

Je ne reçois pas les rappels.

Dans Rouage, ouvrez Réglages › Notifications : l'interrupteur « Rappels » doit être activé, et un bouton vous signale si iOS les bloque. Vérifiez aussi qu'un rappel est choisi pour l'abonnement concerné (fiche › Modifier › Rappel). Les rappels arrivent à l'heure choisie dans ces réglages (9 h par défaut) ; « Envoyer une notification test » permet de vérifier.

Les montants proposés sont-ils exacts ?

Les prix suggérés pour les services courants sont indicatifs et peuvent avoir changé. Vérifiez-les avec votre contrat : Rouage affiche les montants que vous saisissez et ne se connecte à aucun compte bancaire ni fournisseur.

Comment supprimer toutes mes données ?

Dans l'app : Réglages › Effacer toutes les données. Désinstaller l'app supprime également tout.

Comment sauvegarder ou changer d'iPhone ?

Réglages › Sauvegarder crée un fichier complet (icônes et photos comprises) : enregistrez-le dans Fichiers ou iCloud Drive. Sur le nouvel iPhone, Réglages › Restaurer une sauvegarde, puis choisissez « Ajouter » ou « Remplacer tout ».

Comment ouvrir mes données dans un tableur ?

Réglages › Exporter pour un tableur (CSV).
